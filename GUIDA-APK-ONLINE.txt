========================================================
  GUIDA: CREARE L'APK DI MAIR GO! ONLINE (SENZA INSTALLARE NIENTE)
========================================================

Con questo metodo l'APK viene costruito "nel cloud" da GitHub, gratis.
Tu non installi nessun programma sul computer: carichi il progetto e
scarichi l'APK finito. Serve solo un computer con un browser.

TEMPO PREVISTO:
- La prima volta: circa 1-1,5 ore (soprattutto per creare gli account
  e capire i passaggi).
- Le volte successive: 10 minuti.

COSA TI SERVE:
- Un computer (Windows o Mac, indifferente) con connessione internet.
- Un indirizzo email.
- Questo progetto (la cartella che ti ho dato, decompressa).


--------------------------------------------------------
PASSO 1 - CREA UN ACCOUNT GITHUB (gratis)
--------------------------------------------------------
1. Vai su:  https://github.com
2. Clicca "Sign up" e registrati con la tua email (è gratis).
3. Conferma l'email e accedi.

GitHub è il sito dove caricheremo il progetto e dove "la fabbrica
online" costruirà l'APK.


--------------------------------------------------------
PASSO 2 - CREA UN NUOVO "REPOSITORY" (il contenitore del progetto)
--------------------------------------------------------
1. In alto a destra clicca sul "+" e poi "New repository".
2. In "Repository name" scrivi:   mair-go
3. Lascia selezionato "Public" (o "Private", va bene lo stesso).
4. NON aggiungere README, .gitignore o licenza (li abbiamo già).
5. Clicca "Create repository".


--------------------------------------------------------
PASSO 3 - CARICA I FILE DEL PROGETTO
--------------------------------------------------------
Ora sei nella pagina vuota del repository appena creato.

1. Clicca la scritta "uploading an existing file"
   (oppure il pulsante "Add file" -> "Upload files").
2. Apri sul computer la cartella del progetto che ti ho dato.
3. Seleziona TUTTO il contenuto della cartella e trascinalo nella
   pagina di GitHub. IMPORTANTE: carica il CONTENUTO della cartella,
   non la cartella stessa. Devi vedere caricarsi:
     - la cartella  www
     - la cartella  .github
     - il file  package.json
     - il file  capacitor.config.json
     - il file  .gitignore
     - il file  GUIDA-APK-ONLINE.txt

   NOTA: se GitHub non ti mostra la cartella ".github", assicurati di
   averla trascinata. È quella che contiene le istruzioni per costruire
   l'APK. Senza di lei non funziona.

4. In fondo alla pagina clicca il pulsante verde "Commit changes".
5. Aspetta che il caricamento finisca.


--------------------------------------------------------
PASSO 4 - AVVIA LA COSTRUZIONE DELL'APK
--------------------------------------------------------
Il caricamento fa partire tutto da solo. Ma controlliamo:

1. In alto nel repository clicca sulla scheda "Actions".
2. Se compare un avviso che chiede di abilitare i workflow,
   clicca per confermare ("I understand... enable").
3. Dovresti vedere un processo chiamato "Compila APK MAIR GO!"
   con un pallino giallo (in lavorazione) o verde (finito).
   - Se non parte da solo: clicca su "Compila APK MAIR GO!" a
     sinistra, poi sul pulsante "Run workflow" a destra.

4. Aspetta. La costruzione richiede circa 5-10 minuti.
   Il pallino diventa verde con la spunta quando è pronto.
   (Se diventa rosso, vedi la sezione PROBLEMI in fondo.)


--------------------------------------------------------
PASSO 5 - SCARICA L'APK
--------------------------------------------------------
1. Clicca sul processo completato (quello con la spunta verde).
2. Scorri in fondo alla pagina, alla sezione "Artifacts".
3. Trovi un file chiamato "MAIR-GO-APK". Cliccaci sopra per scaricarlo.
4. Si scarica un file .zip: aprilo. Dentro c'è:
       app-debug.apk
   Questo è l'APK di MAIR GO!


--------------------------------------------------------
PASSO 6 - INSTALLA L'APK SUL TELEFONO ANDROID
--------------------------------------------------------
1. Trasferisci il file app-debug.apk sul telefono Android
   (via email a te stesso, WhatsApp, cavo USB o Google Drive).
2. Sul telefono, apri il file.
3. Android dirà che l'app viene "da fonti sconosciute": è normale.
   Concedi il permesso di installare (te lo chiede una volta sola).
4. L'app si installa con la sua icona MAIR GO! sulla schermata Home.

FATTO! Ora è un'app vera: i dati non si perdono più svuotando la cache
del browser.


========================================================
  PER DISTRIBUIRLA AD ALTRI
========================================================
Per far installare MAIR GO! ad altre persone Android, basta inviare
loro il file app-debug.apk (email, link, WhatsApp). Anche loro dovranno
dare il permesso "installa da fonti sconosciute" la prima volta.

Ricorda: l'APK funziona SOLO su Android. Gli iPhone non possono
installare file APK (è una regola di Apple).


========================================================
  PER FARE UNA NUOVA VERSIONE IN FUTURO
========================================================
Quando vuoi aggiornare l'app:
1. Sostituisci i file modificati dentro la cartella "www" del
   repository (Add file -> Upload files).
2. La costruzione riparte da sola.
3. Scarichi il nuovo APK dalla scheda "Actions".
Ci vogliono 10 minuti.


========================================================
  PROBLEMI (se il pallino diventa ROSSO)
========================================================
- Clicca sul processo rosso e poi sul passaggio che ha la X rossa:
  compare un messaggio d'errore.
- Causa più comune: la cartella ".github" non è stata caricata, oppure
  è stata caricata la cartella esterna invece del suo contenuto.
  Soluzione: ricarica assicurandoti che in cima al repository si vedano
  "www", ".github", "package.json" e "capacitor.config.json".
- Se hai bisogno, salva il testo dell'errore e me lo puoi rimandare:
  ti dico cosa sistemare.
